The Python profile installed offline with `--no-index --only-binary=:all: --require-hashes` from verified wheels, and `pip check` reported no broken requirements. Python reports SQLite 3.50.4 and OpenSSL 3.0.21. Their code and pip/setuptools vendored components are part of upstream distributions; the generated component inventory is not a recursive binary/vendored-code SBOM. A full source audit and independent assessment of all vendored/runtime components have not been performed.

No production npm dependencies ship. The VSIX packages application JS/media and the portable Python backend; tests check that source fixtures, local state, environment folders and node_modules are excluded. Preserve upstream license files with any redistributed wheelhouse/toolchain. Recorded SPDX-style metadata is not a substitute for the client's license decision, especially if distributing upstream binaries separately.
